# Inno Setup translations

These Inno Setup message files are from the
[Inno Setup translations list](https://jrsoftware.org/inno-setup/translations)
and [upstream source](https://github.com/jrsoftware/issrc/tree/main/Files/Languages).
The author and contribution information is retained in each file. English uses
the compiler's stock `Default.isl`. Simplified and Traditional Chinese have
separate Windows language IDs; Persian uses the right-to-left layout.
See [the Inno Setup license](Inno-Setup-License.txt). The Persian file differs
from upstream only by trailing whitespace removed from one comment.
